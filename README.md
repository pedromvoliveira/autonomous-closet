# autonomous-closet
A prototype of an autonomous closet.
The user selects an item, with each item being associated with a specific position, and each position corresponding to a number from 1 to 12. The user then enters a number between 1 and 12, triggering a motor that rotates a mechanical structure—which holds a ring containing the various items—so that the item corresponding to the user's chosen number appears at the front of the cabinet.
